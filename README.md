# 咖啡图鉴 · 五个亲手探索的页面

Vite / 原生 JavaScript / CSS 网站。保持纸色、青瓷绿、宋体、暖光与酒红视觉；无账号或后端，支持 GitHub Pages 静态部署。

## 运行

```sh
npm install
npm run dev -- --strictPort
npm test
npm run build
```

本地地址：http://127.0.0.1:5173/

## 页面

- `#/beans`：地球、国家/产区别称搜索、风味 OR 筛选。`#/beans/ETH?region=yirgacheffe` 进入真实国家轮廓，拖动/缩放及键盘平移；14国28产区。旧 `#/beans?country=CHN&region=puer` 兼容。
- `#/processing/natural`：日晒、水洗、蜜处理、湿刨的操作状态、果实剖面、演示/暂停/重置、回顾与记忆题。
- `#/brewing/espresso`：六种器具的独立三维与二维操作场景；参数改变重置制作，完成可带入 DIY。
- `#/drinks`：4大类/24款咖啡，组成拆解、两杯比较与逐款来源。`#/drinks/milk/classic-milk` 分类路由及原饮品地址兼容。
- `#/diy`：选熟豆、称量、研磨、冲煮、配料、命名。支持经典配方/产区/冲煮参数带入，配料修改与撤回、奶泡去重、已知咖啡因和未知状态、本机保存/重载/删除/撤销删除。

会话进度与草稿在 sessionStorage，命名配方在 localStorage。存储被禁止时仍能制作。只运行当前场景，离页释放 WebGL；后台暂停动画；二维备用场景保留全部控制。减少动态效果偏好直接呈现状态。

## 内容边界

- 产区画像是常见倾向，不是某个具体批次承诺；品种、处理、烘焙与冲煮分别记录。
- 场景为教学模型，不模拟精确萃取率、真实生产时间或风味评分。非浓缩出液是可修改的记录示例。
- 冷萃默认50克/600毫升，是本站较轻家用调整；HARIO目前资料为60克/600毫升。Toddy大配方保留在展开阅读。
- 浓缩重量与添加液体体积不混用。奶泡来自已选奶量，发泡后体积不作等值换算。
- 饮品名称不决定咖啡因。无适用测量数据时显示未知；EFSA60ml/80mg仅作为独立示例，不从18g/36g配方推算。已知基底和未知配料可分别填写该份咖啡因；上游参数变化使原基底含量失效。400mg是一般健康成人全天参考上限，不是推荐目标，孕期及哺乳期参考另列。
- 所有配方为示例，各地和门店不同。来源在各页可展开。

## 文件

`src/pages/` 五个页面；`data.js` 产地与原理；`catalog.js` 饮品/配料；`workshop-data.js` 步骤状态；`workbench.js` 共同操作；`workshop-scene.js` 按需三维/二维场景；`vessel-geometry.js` 杯壁、液面和把手的共用几何；`forms.js` 全站统一下拉选择；`diy-model.js` 配方与咖啡因规则；`public/data/` 本地地图与来源。

## 验证

`npm test` 覆盖地图与坐标关联、搜索别称、4/6步骤状态、24款饮品关联、单位、奶泡、未知咖啡因、上游失效与存储数据校验。浏览器检查尺寸1280×720、1440×900、390×844；无自动化浏览器依赖。

地图和 Three.js 首次加载较大，已按页面延迟加载；构建会给出体积提示，不影响本地使用。
